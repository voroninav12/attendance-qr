
# Attendance QR Prototype

Идея из обсуждения:
- Учитель нажимает Start Lesson.
- Генерируется уникальный токен (будущий QR).
- Ученик один раз регистрирует устройство.
- Сканирование QR отмечает присутствие.
- Finish Lesson завершает регистрацию.

Для запуска:
pip install -r requirements.txt
python app.py
